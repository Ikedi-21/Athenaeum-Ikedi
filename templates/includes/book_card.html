Expects a book in the context, which it gets from the surrounding for loop without being passed anything, since an include inherits the context it sits in. Two annotations are read here, average_rating and review_count, and both are added by BookQueryMixin.get_queryset in catalog/views.py. Any view that includes this file has to annotate them or the rating line silently reads as unrated, which is why the mixin annotates them on every list request rather than only when a rating sort is chosen. There is deliberately no line about copies available. A shelf card is for deciding what to look at, and a number that is true when the page is drawn and false by the time it is read is worse than no number. The book's own page says what can be borrowed, and it says it at the moment somebody is actually about to borrow. {% endcomment %}
