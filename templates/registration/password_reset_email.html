{% autoescape off %}{% comment %} The body of the password reset email. This file exists as a project template because Django's shipped version builds its link with {% url 'password_reset_confirm' %}, an unnamespaced name. accounts/urls.py declares an app_name, so that name does not resolve here and the default template would raise NoReverseMatch while trying to send the mail. Autoescaping is turned off because this is a plain text message, not HTML. Escaping would put & and ' into the text a person reads instead of protecting anything, since there is no markup here for an injected character to break out of. MAILERS in settings.py uses the console backend during development, so this arrives in the terminal running the server rather than in a real inbox. That is what makes the whole flow testable without an SMTP account. {% endcomment %}Hello {{ user.get_short_name|default:user.get_username }}, Someone asked to reset the password for your Athenaeum Ikedi account.
