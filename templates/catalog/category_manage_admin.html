{% extends "base.html" %} {% comment %} The subject headings, with what is filed under each. Two counts rather than one, because they answer different questions. A heading with twelve books of which none are currently lent is not the same as an empty heading, and a librarian deciding whether a heading is still needed wants to see both numbers. CategoryManageListView annotates them in one query with a filtered Count. There is no delete button here, and that is deliberate rather than unfinished. Book.category is a protected foreign key, so the database refuses to remove a heading that has books filed under it, which is what stops one careless click from emptying a shelf. A heading that really is empty and really is unwanted can go from the admin site. {% endcomment %} {% block page_title %}Categories{% endblock %} {% block content %}
