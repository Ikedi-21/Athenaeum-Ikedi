{% comment %} enctype is what makes the cover upload work. Without it a browser sends only the file's name and none of its contents, and the field arrives empty with no error to explain why, which is one of the quieter ways a form can waste an afternoon. novalidate turns off the browser's own checking so that every message a librarian sees comes from Django. The rules that matter, such as an ISBN's check digit and a total that cannot fall below the copies on loan, are in the form and the model and cannot be expressed in HTML attributes anyway, so the browser's version would only ever be a partial and differently worded second opinion. {% endcomment %}
