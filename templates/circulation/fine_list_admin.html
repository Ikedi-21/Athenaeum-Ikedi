{% extends "base.html" %} {% comment %} Every fine the library has charged. A fine has no table of its own. It is frozen onto the loan that produced it at the moment the book comes back, which is why this is a list of returned loans with an amount above zero rather than a list of some separate model. Nothing here is a fine record that can drift away from the loan it came from, because there is no such record. A settled fine keeps its amount rather than being zeroed, so this page can answer both "what is still owed" and "what have we charged this term". The tabs across the top choose between those two readings, and the list opens on what is owed, because that is what somebody visiting came to act on. Marking a fine settled is the one action on this page, and it is the only desk action with no student equivalent: a member cannot record their own payment, which is the point of doing it at the desk. {% endcomment %} {% block page_title %}Fines{% endblock %} {% block content %}
