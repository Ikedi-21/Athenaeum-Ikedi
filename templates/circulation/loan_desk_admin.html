{% comment %} The tabs are links and not a dropdown, because there are three of them and a librarian switches between them all day. A link is one click where a select is three, and it gives each state an address that can be bookmarked or left open in a tab. querystring is what makes them safe to combine with the search box. It rebuilds the current query string with state swapped and everything else left alone, so switching tabs keeps whatever was typed. Writing href="?state=overdue" by hand, which is the obvious thing to write, would silently throw the search away. page=None removes the page parameter rather than replacing it. Without that, somebody on page four of everything on loan would land on page four of the overdue list, which may well not exist and is certainly not what they asked for. {% endcomment %}
